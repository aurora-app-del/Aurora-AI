# Aurora Android

Projeto da Aurora com interface Kivy e motor `aurora_7.py`.

## Gerar o APK pelo celular

1. Crie um repositório no GitHub.
2. Envie todos os arquivos deste projeto para a branch `main`.
3. Abra a aba **Actions**.
4. Execute **Build Aurora APK**.
5. Espere a compilação terminar.
6. Abra a execução concluída e baixe o artefato **Aurora-APK**.
7. Extraia o arquivo `.apk` e instale no Android.

O workflow usa uma máquina Linux do GitHub para executar Buildozer e gerar o APK. O celular não precisa instalar Android SDK/NDK.
